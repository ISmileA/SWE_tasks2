# Перед сдачей

1. Проверить PDF перед сдачей: актуальность результатов, имена участников, распределение ответственности и ссылки.
2. Проверить docs/REQUIREMENTS.md: обязательную ссылку на удалённый репозиторий нужно добавить после публикации.
3. Создать репозиторий, выполнить push, предоставить проверяющему доступ и добавить URL в PDF. Приватный URL без доступа проверяющего недостаточен.
4. Самостоятельно воспроизвести по README хотя бы тесты, один /agent запрос и sandbox probe. Уметь показать разные модели в trajectory и объяснить ошибки.
5. Сверить распределение ответственности Арсения и Полины с docs/TEAM.md и подготовить командную демонстрацию.
6. Соблюсти правила курса об автоматизированной генерации и устной защите; никакого внешнего сопровождения при прокторинге.

При публикации не включать runtime/ с пользовательской памятью, .venv/, vendor/ и models/. Их исключает .gitignore. Датасет скачивается с GroupLens; manifest и исследовательская атрибуция входят в проект.
